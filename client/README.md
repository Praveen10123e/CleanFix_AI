# CleanFix AI — Client (Frontend Application)

This folder is reserved for the frontend team to integrate the client application (e.g. Next.js, React, or mobile app).

### Integration Notes:
- The frontend interacts with the system via the FastAPI backend REST endpoints defined in [`shared/api-contract.md`](../shared/api-contract.md).
- Diagnostic data structures and schemas are defined in [`shared/schemas.md`](../shared/schemas.md).
- The client should render diagnostic steps, questions, options, and resolution/escalation states as returned by the backend.
